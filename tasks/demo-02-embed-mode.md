# Задача для «Multibrand Design System» · demo-02 · embed-режим

**Пріоритет:** високий — без нього демо в портфоліо показується з усім власним оточенням і завжди англійською.

Портфоліо вже вбудовує демо так: `…/multibrand-design-system/?lang=en|uk&embed=1`, «на весь екран» — `?lang=…`.

| Параметр | Значення | Поведінка |
|---|---|---|
| `?brand=` | `aurum` · `nova` · `fiesta` · `ultra` | стартовий бренд (невідоме значення → дефолт) |
| `?theme=` | `light` · `dark` | стартова тема (у брифі було `mode` — у демо атрибут `data-theme`, тож і параметр `theme`) |
| `?lang=` | `en` · `uk` | мова інтерфейсу демо |
| `?embed=1` | — | сховати зовнішнє оточення, що не є продуктом (посилання «назад», футер тощо); панель перемикачів лишити |

Параметри читаються один раз при старті й мають пріоритет над збереженим станом.

**postMessage (опційно, для аналітики портфоліо):** при зміні бренду чи теми в embed-режимі
`window.parent.postMessage({ type: "mds:brand-changed", brand, theme }, "*")`.

**Заголовки:** GitHub Pages не ставить `X-Frame-Options`, тож вбудовування вже дозволене. Якщо демо переїде на
Vercel/Cloudflare — `Content-Security-Policy: frame-ancestors 'self' <домен портфоліо>`.

**Перевірка:** 4 бренди × 2 теми × 2 мови з `?embed=1` у iframe шириною 768 і 1440.
