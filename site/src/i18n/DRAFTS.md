# Чернеткове копі

Усі ключі нижче написані як чернетки (`_draft`) за позиціонуванням брифу — пройдися по них і затвердь або перепиши. Шляхи — у `en.json` і `uk.json` (ключі однакові).
Затверджений текст прибирай із цього списку. Чернетки з фактами перевіряй за реєстром у `BRIEF.md` (розділ 3).

| Ключ (префікс) | Що це | Статус |
|---|---|---|
| `preview.banner` | плашка «Preview — content in progress» | `_draft` |
| `nav.cases`, `nav.approach`, `nav.services`, `nav.about` | пункти меню (за брифом: Work · Approach · Services · About · Contact) | `_draft` |
| `meta.approach*`, `meta.cases*`, `meta.services*`, `meta.about*` | title/description нових сторінок | `_draft` |
| `metrics.items[3]` (`new-brand-time`) | 4-та метрика, значення `—` (не виміряно) | `_draft` |
| `brandMorph.*` | заголовок, лід, підписи перемикачів | `_draft` |
| `how.title`, `how.more`, `how.steps[*]` | три кроки Figma → Sync → Ship (замінили попередні «A brand is data…») | `_draft` |
| `newBrand.*` | секція «Новий бренд = один файл» | `_draft` |
| `cases.*` | заголовок, лід і три картки на Home | `_draft` |
| `casesPage.*` | сторінка `/cases`: формат кейсу | `_draft` |
| `approach.*` | уся сторінка `/approach` (шари, осі, компоненти, пайплайн, доказ у коді, межі) | `_draft` |
| `services.*` | пакети й процес з брифу, формулювання — чернетка | `_draft` |
| `about.*` | каркас; потрібні матеріали від Андрія (BRIEF.md, розділ 6) | `_draft` |

Не чернетки (затверджено раніше): `hero.*`, `metrics.items[0..2]`, `demo.*`, `architecture.*`, `audience.*`, `cta.*`, `contact.*`, `footer.*`, `a11y.*`, `meta.home*`, `meta.contact*`.
